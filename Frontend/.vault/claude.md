# Instructions for Claude

Welcome to the AuraMobile project! To reduce token usage and quickly understand the project's established patterns, please use the documentation stored in this `.vault/` folder.

## How to use these files:

1. **Start Here**: Whenever you are given a task that involves architectural decisions, navigation changes, or state management, please read the corresponding markdown files in this directory first (e.g., `architecture.md`, `navigation.md`, `state.md`).
2. **Context Establishment**: Use these summaries to build your context instead of running expensive searches across the entire `src/` directory or reading large files like `App.tsx` from scratch.
3. **Adhere to Patterns**: These documents outline the specific tools and patterns used in the project (such as using React Context for state instead of Redux, and custom navigation handling). Please align your proposed solutions with these patterns.
4. **Keep it Updated**: If you make significant architectural changes, please update the relevant `.md` files in this vault to keep the context accurate for future sessions.
